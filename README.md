## 维护规则

- 新资源优先保留官方仓库、官网或官方文档，注明原始分享来源。
- 以项目身份去重；多个来源合并到同一条记录。
- 不把设计工具、组件库与 AI Skills 混为一谈。
- 资源收录不代表已测试或推荐用于生产。使用前检查维护状态、兼容性、收费条款及许可证。
- 部分项目有收费内容或额外使用限制；未逐项审查许可证，不默认全部免费或允许商用。
- 没有核实官方 GitHub 地址的项目仅保留官网，不用第三方仓库冒充官方仓库。
